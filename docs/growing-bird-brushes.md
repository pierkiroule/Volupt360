# Collection progressive de matières

Le menu commence par un emplacement à remplir, ou restaure la palette précédemment sauvegardée. Le bouton + permet de composer une brosse procédurale, dans une limite de 18. Une création la sélectionne et sauvegarde automatiquement les paramètres sur cet appareil.

La collection reste disponible lors du retour à l’accueil. Un toucher sélectionne une matière ; maintenir le canevas fait sculpter l’oizo, sans dessiner avec le doigt. Les dépôts composent une musique spatialisée qui anime les visuels en retour. Le menu se masque pour le cadrage photo.

Les 18 moteurs artistiques restent des primitives paramétrables : rubans, dépôts, réseaux et particules. Les textures sont fabriquées hors rendu et libérées avec le moteur. Les photos et API de médias ne sont plus utilisées.

Voir [l’atelier procédural et la sauvegarde](procedural-brush-palette.md).
